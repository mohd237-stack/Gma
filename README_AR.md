# تطبيق المسابقة الثقافية – صيف القمع ١٤٤٨هـ

تطبيق ويب متجاوب يعمل على الجوال، ولا يطلب إنشاء حساب للمشارك. يحفظ الأسماء والأرقام والإجابات في **Netlify Blobs**، وتظهر النتائج والسحب العشوائي في صفحة إدارة محمية برقم سري.

## المزايا

- الاسم الرباعي، الفئة، ورقم الجوال للمشارك أو من ينوب عنه.
- ١٢ سؤالًا مع إجابة واحدة لكل سؤال.
- عدم إظهار الدرجة أو الإجابات الصحيحة للمشارك.
- منع تكرار نفس الاسم مع نفس رقم الجوال.
- لوحة إدارة تعرض النتائج والدرجات.
- فرز فائز عشوائي من أصحاب الإجابات الكاملة أو من الجميع.
- اختيار فئة السحب ومنع تكرار الفائز.
- فتح وإغلاق استقبال المشاركات.
- تصدير المشاركات بصيغة CSV.
- قابل للتثبيت كتطبيق على شاشة الجوال PWA.

## النشر على Netlify

1. ارفع **المجلد كاملًا** إلى مستودع GitHub، ثم اربطه بمشروع Netlify. يفضل الربط عبر GitHub حتى تعمل Functions والتحديثات بسهولة.
2. في Netlify افتح: **Project configuration → Environment variables**.
3. أضف متغيرًا باسم:

   `ADMIN_PASSWORD`

   واجعل قيمته الرقم السري الذي طلبته:

   `Mohd1435`

4. نفّذ Deploy جديد بعد إضافة المتغير.
5. صفحة المشاركين هي رابط الموقع الرئيسي، وصفحة الإدارة:

   `/admin.html`

> مهم: لا تكتب الرقم السري داخل ملفات JavaScript العامة. حفظه في Environment Variables يجعله متاحًا لدوال الخادم فقط.

## تحديث التطبيق

عدّل الملفات في GitHub ثم احفظ Commit؛ سيعيد Netlify النشر تلقائيًا. البيانات محفوظة في Netlify Blobs ولا تُحذف عند كل تحديث للموقع.

## ملاحظات الخصوصية

التطبيق يجمع أسماء وأرقام جوال، لذلك يفضل قصر استخدام البيانات على إدارة المسابقة والسحب، ثم حذفها بعد انتهاء الغرض منها.
